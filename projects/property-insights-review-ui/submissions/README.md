# Submissions

Create one folder per submission:

```text
projects/property-insights-review-ui/submissions/<your-github-handle>/
```

Your folder should include:

- `README.md`: setup, run, validate, and test commands
- `WRITEUP.md`: workflow, component structure, state model, and tradeoffs
- runnable source code
- screenshots or screen recording links
- any tests or accessibility checks

Use mock data only. Do not commit secrets, private data, customer screenshots,
internal screenshots, or local-machine paths.
