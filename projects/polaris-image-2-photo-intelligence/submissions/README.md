# Submissions

Create one folder per submission:

```text
projects/polaris-image-2-photo-intelligence/submissions/<your-github-handle>/
```

Your folder should include:

- `README.md`: setup, run, validate, and benchmark commands
- `WRITEUP.md`: architecture, tradeoffs, failure modes, and next steps
- source code or links to the artifact
- sample input/output files
- any tests or validation scripts

Do not commit secrets, private datasets, customer images, internal prompts, or
local-machine paths.
