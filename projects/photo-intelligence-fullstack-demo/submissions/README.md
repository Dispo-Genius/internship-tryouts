# Submissions

Create one folder per submission:

```text
projects/photo-intelligence-fullstack-demo/submissions/<your-github-handle>/
```

Your folder should include:

- `README.md`: setup, run, validate, test, and demo commands
- `WRITEUP.md`: architecture, API design, state model, tradeoffs, and next steps
- runnable frontend/backend source code
- sample output JSON and screenshots or demo video link
- any validator, API, or UI tests

Use public-safe images only. Do not commit secrets, private data, customer
photos, internal prompts, API keys, or local-machine paths.
