# Contributing A Tryout Submission

Thanks for building something for Covent.

## Required Submission Shape

Your submission should include:

- Source code or artifact links.
- A `README.md` with setup and run commands.
- A `WRITEUP.md` with decisions, tradeoffs, failure modes, and next steps.
- Any tests, validators, screenshots, or sample outputs needed to evaluate it.

## Pull Request Checklist

- [ ] The project runs from a clean checkout.
- [ ] Setup commands are documented.
- [ ] Validation commands are documented.
- [ ] No secrets or private data are committed.
- [ ] The writeup explains what was intentionally left out.

## AI Tooling

Use AI tools. We expect it. The bar is whether you can use them to produce a
working artifact with good engineering judgment.
