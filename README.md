# Covent Internship Tryouts

This repository hosts public tryout projects for the Covent internship program.

Each project is sized for roughly 1 to 2 weeks of focused work. A strong
submission should be runnable, well-tested, and honest about tradeoffs.

## How To Submit

1. Pick a project under `projects/`.
2. Build your solution in your own fork.
3. Add a `WRITEUP.md` that explains your approach, decisions, tradeoffs, and
   what you would do next.
4. Include a cost/deployment report and a walkthrough video link when the
   project asks for a runnable product demo.
5. Open a pull request into this repo.

Code submissions should live under:

```text
projects/<project-id>/submissions/<your-github-handle>/
```

Non-code submissions can link to a public artifact in the pull request body.

## Review Bar

We review for:

- A runnable artifact, not just a report.
- Clear setup and verification commands.
- Deterministic validation where practical.
- Thoughtful use of AI tools.
- Good judgment about scope and omissions.
- A concise writeup that makes your reasoning visible.

Do not include secrets, private customer data, raw proprietary datasets, or
credentials in submissions.

See `RUBRIC.md` for the scoring rubric we use to judge submissions.
